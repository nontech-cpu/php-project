# Gumming Sheet Price Calculator

This is a **PHP + MySQL** based project that provides a customer‑facing calculator and an admin panel for managing pricing.

## Key highlights
- **Tech stack:** PHP (PDO), MySQL, HTML/CSS, vanilla JavaScript
- **Features:**
  - Dynamic pricing fetched from MySQL
  - Secure admin panel for CRUD operations
  - Responsive UI for customers
